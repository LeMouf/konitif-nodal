# Nodal reference

This directory contains authored, machine-readable documentation for
`@konitif/nodal`.

- [`catalog.json`](catalog.json) groups graph, Composition, dialect, runtime and integration responsibilities.
- [`diagrams.json`](diagrams.json) describes command-based graph editing and observable execution.

These files support documentation tooling. They do not mutate a graph, select a
dialect or execute a workflow.
