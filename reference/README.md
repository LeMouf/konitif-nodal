# Nodal reference

This directory contains authored, machine-readable documentation for
`@konitif/nodal`.

- [`catalog.json`](catalog.json) groups graph, Composition adaptation, dialect, projection-registry, runtime and integration responsibilities.
- [`diagrams.json`](diagrams.json) describes command-based graph editing, observable execution and scoped presentation lifecycle.

These files support documentation tooling. They do not mutate a graph, select a
dialect or execute a workflow.
